### 1. 单选题

下面选项中，用于为页面添加视频的标签是（）。

- A. audio
- B. video
- C. text
- D. image

**答案**：B

### 2. 单选题

下列选项中，用来设置一行内容的垂直对齐方式的是（）。

- A. height
- B. align
- C. valign
- D. background

**答案**：C
**解析**：在HTML中，valign属性用于设置表格单元格中内容的垂直对齐方式，可选值有top、middle、bottom等。height设置高度，align设置水平对齐，background设置背景，因此正确答案是C。

- B. 微软(Microsoft)
- C. 网景公司(Netscape)
- D. 万维网联盟(W3C)

- A. 谷歌浏览器
- B. 火狐浏览器
- C. 欧朋浏览器
- D. IE浏览器

**答案**：D

- C. `<a>http://www.w3school.com.cn</a>`

### 120. 单选题

阅读下面的代码，执行后控制台两行依次输出的是（　）

```javascript
var funcs = [];
for (var i = 0; i < 3; i++) {
  funcs.push(function () { return i; });
}
console.log(funcs[0](), funcs[1](), funcs[2]());

var lets = [];
for (let j = 0; j < 3; j++) {
  lets.push(function () { return j; });
}
console.log(lets[0](), lets[1](), lets[2]());
```

- A. 第一行 `3 3 3`，第二行 `0 1 2`
- B. 第一行 `0 1 2`，第二行 `0 1 2`
- C. 第一行 `3 3 3`，第二行 `3 3 3`
- D. 第一行 `0 1 2`，第二行 `3 3 3`
- E. 代码直接抛错，因为 let 不能用在 for 循环里

**答案**：A
**解析**：第一段用 var 声明的 i 属于函数作用域，整个循环从头到尾共用同一个变量。循环结束时 i 已经加到 3，三个闭包读到的都是这同一个 i，所以输出 `3 3 3`。第二段用 let 声明的 j 属于块级作用域，for 循环的每一次迭代都会创建一个新的绑定，并把当次的值捕获进那个闭包，因此三个函数分别返回 0、1、2。E 是明显的错误说法，let 完全可以用在 for 循环里，这正是它相对 var 的改进之一。故选 A。
