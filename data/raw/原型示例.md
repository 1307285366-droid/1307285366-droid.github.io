## JavaScript 基础

### 1. 单选题

用于声明块级作用域变量的关键字是？

- A. var
- B. let
- C. function
- D. class

**答案**：B
**解析**：示例数据，来自附件 原型/index.html。`let` 声明块级作用域变量，`var` 是函数作用域。

---

### 2. 多选题

以下哪些属于 JavaScript 基本数据类型？

- A. String
- B. Number
- C. Array
- D. Boolean

**答案**：A、B、D
**解析**：示例数据，来自附件 原型/index.html。Array 是引用类型（对象），不属于基本数据类型。
